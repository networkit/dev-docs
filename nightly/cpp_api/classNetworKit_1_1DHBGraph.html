bool addEdge(node u, node v, edgeweight ew = defaultEdgeWeight, bool do_update = true)¶

Insert an edge between the nodes u and v. If the graph is weighted you can optionally set a weight for this edge. The default weight is 1.0. Note: Multi-edges are not supported and will NOT be handled consistently by the graph data structure. It is possible to check for multi-edges by enabling parameter “checkForMultiEdges”. If already present, the new edge is not inserted. Enabling this check increases the complexity of the function to O(max(deg(u), deg(v))).

Parameters:

  • u – Endpoint of edge.

  • v – Endpoint of edge.

  • weight – Optional edge weight.

  • do_update – (Optional) If set to true, the function will update existing edges with new data; if false, it will only insert new edges.

Returns:

true if edge has been added, false otherwise (in case checkMultiEdge is set to true and the new edge would have been a multi-edge.)

void addEdges(std::vector<WeightedEdge> &&edges, bool do_update)¶

Adds a collection of weighted edges to the DHBGraph.

This function takes a vector of WeightedEdge objects and attempts to add them to the DHBGraph instance. It processes the edges in parallel. Depending on the value of do_update, the function either updates existing edges with new data or inserts new edges. After adding the edges, edge ids of the new edges will not be updated. Please call indexEdges(true) to index all the edges if needed.

Parameters:

  • weighted_edges – [in] A vector of WeightedEdge objects to be added to the graph. This parameter is an rvalue reference.

  • do_update – [in] A boolean flag indicating whether existing edges should be updated. If true, the function will update existing edges; if false, it will only insert new edges.

void swapEdge(node source_a, node target_a, node source_b, node target_b)¶

Swaps edge target of edge (source_a, target_a) with edge target of edge {source_b, target_b} such that (source_a, target_b) and (source_b, target_a).

Edge weights or edge ids are preserved.

A std::runtime_error() is thrown if:

  • edge (source_a, target_a) does not exist

  • edge (source_b, target_b) does not exist

  • edge (source_a, target_b) does already exist

  • edge (source_b, target_a) does already exist
