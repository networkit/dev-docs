template<class GraphT, class TreeT = AdjListGraph<typename GraphT::NodeT, typename GraphT::EdgeWeightT>>
class SteinerTree : public NetworKit::Algorithm¶

Computes a light tree that connects a given set of terminal nodes, possibly through other nodes. Finding the lightest one is NP-hard. This is the approximation algorithm from “A faster

approximation algorithm for the Steiner problem in graphs” by K. Mehlhorn (1988): the weight of the result is at most 2(1 - 1/l) times the optimal one, where l is the number of leaves of an optimal tree, which is at most the number of terminals. The resulting tree is then replaced by a minimum spanning tree of the subgraph induced by its nodes, and leaves that are not terminals are removed. This keeps the guarantee and often makes the tree lighter. It runs in O(m log n) time.

Unweighted graphs are treated as having unit weights. Path lengths and the total weight are computed in a 64-bit integer type, or in double for floating-point weights, so that they do not overflow narrow edge weight types.

Template Parameters:

  • GraphT – The type of the input graph.

  • TreeT – The type of the resulting tree, a mutable graph type.

inline const TreeT &getTree() const¶

Returns the tree, a weighted graph with the same node ids as the input graph. Nodes deleted from the input graph are deleted from the tree too, and nodes outside the tree have no edges. Its edges have unit weight if the input graph is unweighted. It has no edges if the terminals are not connected.

Returns:

The tree connecting the terminals.
